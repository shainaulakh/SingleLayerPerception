## About This Workshop

This workshop explores how single-layer artificial neural networks
make predictions using inputs, weights, biases, and activation functions.

Our work builds on the professor's original notebook. We keep the
original content and add our implementation and explanations in
the same notebook.

## Topics Covered

- Activation functions: identity, binary step, sigmoid, tanh, and ReLU.
- Canada's Wonderland prediction example.
- Error calculation and a gradient descent weight update.
- Logic gates implemented using PyTorch and TensorFlow.
- Movie decisions using different weights and biases.
- Prostate cancer prediction using parameters from the class notes.
- Visualization of model outputs and the decision boundary.
- Talking points and an explanation of backpropagation.
